# Star Ring Dodge

纯前端 Canvas 太空生存射击小游戏。玩家驾驶飞船在流动星域中规避陨石流，回收能量核心，使用激光清除障碍，并通过跃迁门选择下一片区域。

当前版本：v3.6

## 运行方式

在线访问：https://ronny-7.github.io/star-ring-dodge/

直接用浏览器打开 `index.html` 即可运行，不需要安装依赖或启动构建工具。

浏览器不支持 Web Audio API 时，游戏仍可运行，只是不会播放合成音效。

## 操作

### 电脑端页面

- 方向键 / WASD：移动
- J：发射激光
- Space：开始或重新开始
- P / Esc：暂停或继续

### 手机端页面

- 拖动左下角手势摇杆：移动
- 点击”开火”：发射激光
- 点击”暂停”：暂停或继续
- 点击”横屏”：进入横屏模式；浏览器不支持系统锁横屏时，页面会启用强制横屏布局，再次点击”退出”可恢复
- 在设置里关闭音效后，手机触觉震动也会停止

## 当前内容

- 流动星域系统：不同区域拥有独立视觉主题、陨石压力、核心与道具节奏
- 精英陨石：体积约为普通陨石两倍、需要多次命中才碎，会缓慢追踪飞船，击破后分裂成数颗普通陨石
- 精英陨石出现概率由星域决定（密集陨带最高、安定漂流区最低），撞上它不会像普通陨石那样消失，而是把飞船弹开
- 跃迁到新星域会甩掉当前星域的精英陨石
- 可探索游玩区域：更大的世界坐标配合跟随相机，玩家可持续穿越多屏星域
- 定期出现双跃迁门，玩家可选择下一片探索区域
- Canvas 自适应显示尺寸（DPR 高清渲染，手机不模糊）
- 键盘和触控手势双输入
- 更灵敏的飞船机动手感（快速起步、平滑转向、松手制动）
- 手机端横屏布局与强制横屏兜底（切换带过渡动画）
- 移动端实体尺寸自适应缩放，窗口变化只调整视口，不会拉伸已探索世界坐标
- 按住连发射击
- 陨石、能量核、护盾和双发道具
- 飞船与陨石精细 Canvas 绘制（动态推进器、能量高光、碎岩轮廓、裂隙矿物光点）
- 推进器尾焰、命中冲击环、陨石爆炸、拾取和跃迁闪光特效
- 最高分本地保存
- 游戏结束统计（含分数、存活时间、击毁/回收、跃迁次数和命中率；击破过精英陨石时追加一栏）
- 屏幕边缘陨石预警
- 拾取、受伤和护盾浮动反馈
- Web Audio API 合成音效（射击 / 击中 / 爆炸 / 拾取 / 受伤）
- 手机触觉反馈，按事件强度区分震动时长，并跟随音效开关启停
- 设置弹窗（音乐 / 音效开关、3 种飞船外形、3 种颜色主题）
- 成就与累计统计（v3.4）：跨局记录游玩数据，达成成就时局内飘字提示，结算面板展示累计局数、累计击毁与本局新达成成就
- 8 个星域（含引力涡流、静默星云、极光带、恒星熔炉），涡流弯曲陨石轨迹、星云遮蔽视野并加快补给
- 常驻小地图雷达：按世界比例缩放显示玩家、视口、跃迁门（强调）、陨石与道具，移动端自动避让手势摇杆
