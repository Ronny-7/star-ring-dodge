# Star Ring Dodge

纯前端 Canvas 太空生存射击小游戏。玩家驾驶飞船在流动星域中规避陨石流，回收能量核心，使用激光清除障碍，并通过跃迁门选择下一片区域。

当前版本：v4.6.4（3D 版，`feat/single-page-v4.6` 分支）

## 3D 版说明

v4.0 把游戏改成了真 3D：60 km 开放场地、自由飞行、WebGL 实时渲染。v4.1 扩大了场地与可视距离，限制了同屏陨石数量，并为三套皮肤做出了真正的 3D 机体。v4.2 重做奖励轮廓（三种奖励按暗色轮廓识别）并新增模型展示页 `showcase.html`。v4.3 补上三处手感与反馈：加力推进、跃迁门的文字说明、陨石被击碎时的碎片特效。v4.4 按写实语言重做三角翼与飞碟：三角翼改成翼身融合的隐形飞翼，飞碟改成带连续外环装甲带的工业探测盘；三艘皮肤现在共用同一套结构契约，展示页也改为并排展示三艘。v4.5 把展示页变成站点落地页：游戏简介、操作说明、四视图 3D 资产舞台（全屏只作用于舞台）和「开始游戏」入口都在这一页。v4.6 把落地页和游戏合到同一个 `index.html`：落地视图是首屏，飞船/奖励/陨石可拖动旋转、滚轮或双指缩放；点「开始游戏」才加载游戏并在原地切到游戏视图，游戏视图只保留画面与分数、生命、最高分，暂停面板的「返回主页」回到落地视图（离开即结束本局）。v4.6.1 让落地视图可以点任意单个模型单独查看（再点空白处或切视图返回分组），并把加力时的尾焰收敛到更自然的长度与亮度。v4.6.2 为三角翼、奖励和跃迁圈增加硬表面层次，并重做游戏内设置面板的 HUD 视觉层级。v4.6.4 修复三角翼展示的深度冲突与近距离裁剪，增加前缘包边，并扩大跃迁圈接触范围。

- 渲染用 three.js + WebGL：PBR 材质、实时阴影、ACES 色调映射
- 2D 版（v3.8）原样保留在 `main` 分支
- 3D 版使用独立的存档 key，与 2D 版的最高分和成就互不干扰
- 场地为 60000 × 60000 × 60000（宽 × 高 × 深），从中心起飞；可见围栏已移除，远处保留不可见软边界；普通陨石与拾取物按玩家距离局部生成/回收；同屏陨石上限 30
- 飞船外形与颜色会跨会话记忆

## 运行方式

**3D 版需要本地服务器**（three.js 是 ES module，不能用 `file://` 打开）：

```bash
node tests/serve.js 8123
```

然后访问 <http://127.0.0.1:8123/>：落地视图是首屏，点「开始游戏」切到游戏视图；也可以直接用 <http://127.0.0.1:8123/index.html#play> 进入游戏视图。

在线访问：https://ronny-7.github.io/star-ring-dodge/（`main` 分支的 2D 版）

浏览器不支持 Web Audio API 时，游戏仍可运行，只是不会播放合成音效。

## 操作（3D）

### 电脑端

- **W / S**：沿机头方向前进 / 后退
- **Shift（按住）**：加力推进，前进更快，后退与横移不加速
- **A / D**：左右横移（不改变朝向）
- **鼠标移动**：左右偏航、上下俯仰（自动进入鼠标锁定）
- **鼠标左键**：发射激光（按住连发）
- **鼠标右键拖动**：浏览器拒绝鼠标锁定时，用它转视角
- **J 或 空格**：也可以发射激光（沿准星方向）
- **P / Esc**：暂停

### 手机端

- **左半屏拖动**：前进/后退 + 左右横移（推到底进入加力）
- **右半屏拖动**：转视角（偏航 + 俯仰）
- **开火 / 暂停**：屏幕按钮

## 当前内容

- 真 3D 开放场地：60000 × 60000 × 60000，从中心起飞；可见围栏已移除，远处保留不可见软边界；普通陨石与拾取物围绕玩家局部生成/回收，自由飞行、WebGL 实时渲染、PBR 材质与实时阴影
- 软边界：远离中心、贴近 60 km 场地边缘时推回，保留闪避压力
- 陨石围绕玩家生成、四处游荡，跑到远处会被回收；随时间提速，同屏上限 30
- 加力推进：按住 Shift（触屏把左摇杆推到边缘）提升前进速度与加速度，只作用于前飞，不消耗资源
- 程序化星云穹顶、双层视差尘埃与远景行星，随星域 tint 变化
- 三套真实 3D 机体（战斗机 / 三角翼 / 飞碟）与三种配色，选择跨会话保存
- 落地视图：飞船、奖励、陨石来自游戏同一套模型工厂，可拖动旋转、滚轮或双指缩放，点任意单个模型可单独查看；切视图重置机位
- 三种共享程序岩体（块状/长轴/断裂）+ 程序颜色/凹凸贴图，逐颗矿物色调与精英/受击高亮；三艘皮肤均为独立程序化机体
- 能量核与护盾/双发道具带光晕、光柱和旋转光环，并放大了拾取判定
- 伪球体光照与指数距离雾，远处目标自然淡出
- 双跃迁门浮在飞船前方，穿过即选择下一片星域
- 跃迁门出现时屏幕中央显示 2.5 秒说明，两扇门各自标出目的星域名，左上角倒计时继续
- 以飞船为中心、按朝向旋转箭头的俯视雷达，量程 1300，显示核心与道具
- Canvas 自适应尺寸，DPR 封顶 2 以保证手机帧率
- 键盘 + 鼠标、触控双摇杆双输入
- 按住连发射击，激光沿准星方向
- 陨石、能量核、护盾和双发道具
- 推进器尾焰、命中冲击环、陨石爆炸、拾取和跃迁闪光特效
- 击碎陨石时抛出岩石碎片、白闪、矿物色冲击环与火花，精英陨石为更大更亮的琥珀色版本；未击碎只留火花；同屏碎片组上限 8，触屏或窄屏时每组 3 片、火花减半
- 最高分与累计成就本地保存（3D 版独立 key）
- 游戏结束统计（分数、存活时间、击毁/回收、跃迁次数和命中率）

### 纵切片尚未包含

- 引力涡流、静默星云、极光带、恒星熔炉的特殊机制
- 3D 下的屏幕边缘陨石预警

### 已包含的周边系统

- Web Audio API 合成音效（射击 / 击中 / 爆炸 / 拾取 / 受伤）
- 手机触觉反馈，按事件强度区分震动时长，并跟随音效开关启停
- 设置弹窗（音乐 / 音效开关、3 种飞船外形、3 种颜色主题）
- **背景音乐默认关闭**，在设置里手动开启；音乐是程序合成的慢速小调和弦铺底，带混响长尾，不打包任何音频文件
- 成就与累计统计：跨局记录游玩数据，达成成就时局内飘字提示，结算面板展示累计局数、累计击毁与本局新达成成就
- 8 个星域定义（星域参数已接入战斗节奏，涡流与星云的特殊效果待移植）
- 中英文语言切换：设置弹窗内一键切换，默认中文，覆盖 HUD、设置、开始/暂停/结算与星域名，选择跨会话记忆

## 文件结构

```text
index.html        站点页面：落地视图（模型舞台、简介、操作）+ 游戏视图
views.js          两个视图的切换、按需加载游戏脚本、#play 入口
styles.css        界面样式、响应式布局和移动端横屏样式
showcase.css      落地视图（模型舞台与说明卡）样式
showcase.js       落地视图的 three.js 模型舞台（拖动旋转、滚轮/双指缩放、全屏）
config.js         游戏参数和界面文案（含所有可调数值与 3D 机位）
projection.js     朝向基与追踪相机计算（纯函数，可单测）
world3d.js        three.js/WebGL 场景、材质、光照与实体同步
app.js            游戏状态、玩法逻辑、HUD 与结算
input.js          键盘、鼠标视角、触控和设置交互控制器
audio.js          Web Audio 音效、背景音乐和触觉反馈
storage.js        最高分和累计档案存取
renderer.js       Canvas 帧循环
vendor/           three.js 运行时（含 LICENSE）
GLOSSARY.md       领域术语表
docs/adr/         关键取舍的决策记录
tests/smoke.test.js       Node 原生冒烟测试（含 Edge 页面集成）
tests/projection.test.js  投影数学单元测试
tests/serve.js            本地静态服务器（3D 版必需）
TODO.md           已规划但尚未实现的玩法方向
```

运行测试：`npm test`。测试使用 Node.js 内置测试模块，并在检测到 Microsoft Edge 时加载真实页面执行浏览器集成冒烟测试；未安装 Edge 时该浏览器测试会跳过，模块级测试仍会执行。
