# Star Ring Dodge

一个纯前端 Canvas 太空生存射击小游戏。玩家驾驶飞船在星环航道中躲避陨石，回收能量核心，并使用激光清除障碍。

## 运行方式

直接用浏览器打开 `index.html` 即可运行，不需要安装依赖或启动构建工具。

## 操作

- 方向键 / WASD：移动
- J：发射激光
- Space：开始或重新开始
- P / Esc：暂停或继续
- 触控设备：使用屏幕上的方向、发射和暂停按钮

## 当前内容

- Canvas 自适应显示尺寸
- 键盘和触控双输入
- 按住连发射击
- 陨石、能量核、道具、护盾和双发道具
- 最高分本地保存
- 游戏结束统计
- 屏幕边缘陨石预警
- 拾取、受伤和护盾浮动反馈

## 文件结构

```text
index.html   页面结构
styles.css   界面样式和响应式布局
config.js    游戏参数和界面文案
app.js       游戏主逻辑、绘制、输入和碰撞
```
