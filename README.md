# Star Ring Dodge

纯前端 Canvas 太空生存射击小游戏。玩家驾驶飞船在流动星域中规避陨石流，回收能量核心，使用激光清除障碍，并通过跃迁门选择下一片区域。

当前版本：v3.0

## 运行方式

在线访问：https://ronny-7.github.io/star-ring-dodge/

直接用浏览器打开 `index.html` 即可运行，不需要安装依赖或启动构建工具。

浏览器不支持 Web Audio API 时，游戏仍可运行，只是不会播放合成音效。

## 操作

### 电脑端页面

- 方向键 / WASD：移动
- J：发射激光
- Space：开始或重新开始
- P / Esc：暂停或继续

### 手机端页面

- 拖动左下角手势摇杆：移动
- 点击”开火”：发射激光
- 点击”暂停”：暂停或继续
- 点击”横屏”：进入横屏模式；浏览器不支持系统锁横屏时，页面会启用强制横屏布局，再次点击”退出”可恢复
- 在设置里关闭音效后，手机触觉震动也会停止

## 当前内容

- 流动星域系统：不同区域拥有独立视觉主题、陨石压力、核心与道具节奏
- 定期出现双跃迁门，玩家可选择下一片探索区域
- Canvas 自适应显示尺寸（DPR 高清渲染，手机不模糊）
- 键盘和触控手势双输入
- 手机端横屏布局与强制横屏兜底（切换带过渡动画）
- 移动端实体尺寸自适应缩放
- 按住连发射击
- 陨石、能量核、护盾和双发道具
- 飞船与陨石精细 Canvas 绘制（发光、渐变、立体感）
- 推进器尾焰、命中冲击环、陨石爆炸、拾取和跃迁闪光特效
- 最高分本地保存
- 游戏结束统计（含分数、存活时间、击毁/回收、跃迁次数和命中率）
- 屏幕边缘陨石预警
- 拾取、受伤和护盾浮动反馈
- Web Audio API 合成音效（射击 / 击中 / 爆炸 / 拾取 / 受伤）
- 手机触觉反馈，按事件强度区分震动时长，并跟随音效开关启停
- 设置弹窗（音乐 / 音效开关、3 种飞船外形、3 种颜色主题）

## 文件结构

```text
index.html   页面结构
styles.css   界面样式、响应式布局和移动端横屏样式
config.js    游戏参数和界面文案（含所有可调数值）
app.js       游戏主逻辑、绘制、输入、横屏模式和碰撞
```
