# Star Ring Dodge

纯前端 Canvas 太空生存射击小游戏。玩家驾驶飞船在星环航道中规避陨石流，回收能量核心，并使用激光清除障碍。

当前版本：v2.0

## 运行方式

在线访问：https://ronny-7.github.io/star-ring-dodge/

直接用浏览器打开 `index.html` 即可运行，不需要安装依赖或启动构建工具。

## 操作

### 电脑端页面

- 方向键 / WASD：移动
- J：发射激光
- Space：开始或重新开始
- P / Esc：暂停或继续

### 手机端页面

- 拖动左下角手势摇杆：移动
- 点击“开火”：发射激光
- 点击“暂停”：暂停或继续
- 点击“横屏”：进入横屏模式；浏览器不支持系统锁横屏时，页面会启用强制横屏布局，再次点击“退出”可恢复

## 当前内容

- Canvas 自适应显示尺寸
- 键盘和触控手势双输入
- 手机端横屏布局与强制横屏兜底
- 移动端实体尺寸自适应缩放
- 按住连发射击
- 陨石、能量核、护盾和双发道具
- 最高分本地保存
- 游戏结束统计
- 屏幕边缘陨石预警
- 拾取、受伤和护盾浮动反馈

## 文件结构

```text
index.html   页面结构
styles.css   界面样式、响应式布局和移动端横屏样式
config.js    游戏参数和界面文案
app.js       游戏主逻辑、绘制、输入、横屏模式和碰撞
```
